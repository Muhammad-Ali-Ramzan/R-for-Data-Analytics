# Data Analytics Using R

## Overview

This repository contains my work completed as part of a Data Analytics course. The project demonstrates the complete data analysis workflow using R, including data collection, cleaning, manipulation, statistical analysis, visualization, and interpretation of results.

The objective of this project is to apply fundamental data analytics concepts to real-world datasets and generate meaningful insights through data-driven analysis.

---

## Course Description

The Data Analytics course provides a gentle introduction to the responsible collection and reporting of data, data manipulation, data analytics, prediction from data, and data visualization.

The course equips learners with the skills required to:

* Understand fundamental data analytics concepts
* Explain basic statistical terminology
* Manipulate and transform datasets
* Perform exploratory data analysis (EDA)
* Make simple predictions from data
* Create meaningful and appealing visualizations
* Interpret and communicate analytical findings

The course covers the complete data analysis process, from understanding data to reporting results through practical case studies, lab assignments, and quizzes.

## Project Workflow

### 1. Data Collection

* Import dataset into R
* Understand data structure and variables

### 2. Data Cleaning

* Handle missing values
* Remove duplicates
* Correct data inconsistencies

### 3. Data Manipulation

* Filter and transform data
* Create derived variables
* Aggregate and summarize information

### 4. Exploratory Data Analysis (EDA)

* Analyze distributions
* Identify patterns and trends
* Examine relationships between variables

### 5. Data Visualization

* Create charts and graphs
* Communicate insights effectively
* Support findings with visual evidence

### 6. Interpretation and Reporting

* Draw conclusions from analysis
* Explain key findings
* Provide data-driven recommendations
